### 🪾 O Trunk-based Development
O Desenvolvimento Baseado em Tronco é uma prática de controle de versão onde desenvolvedores integram códigos frequentemente em uma única branch principal (o trunk ou main). Substituindo branches de longa duração, ela elimina conflitos de merge complexos e viabiliza a integração e entrega contínua (CI/CD) de alta velocidade.

### 📚 A aplicação
Trata-se de um simples programa de gerenciamento de biblioteca utilizando as técnicas bássicas de POO para experienciar a prática do TBD no desenvolvimento de um projeto.
